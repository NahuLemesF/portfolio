# Nahuel Lemes Portfolio

Este repositorio contiene mi portfolio personal como desarrollador. Mas que una simple landing, este proyecto funciona como mi README de presentacion: un lugar donde muestro quien soy, como pienso el desarrollo, y la forma en la que combino producto, frontend, backend y QA en una misma base tecnica.

## Sobre el proyecto

El sitio esta pensado para presentar mi perfil profesional, experiencia, stack, proyectos y una via de contacto clara en una SPA con foco en narrativa visual, performance y una experiencia cuidada.

## Perfil

Soy Nahuel Lemes, Fullstack Developer & QA Engineer. Me interesa construir software con buena UX, codigo mantenible y una mirada fuerte sobre la calidad, desde la idea inicial hasta el despliegue.

## Stack

- React
- Vite
- Tailwind CSS
- Motion
- TypeScript

## Scripts

- `npm install` para instalar dependencias
- `npm run dev` para levantar el entorno local
- `npm run build` para generar la build de produccion

## Objetivo

Este portfolio busca resumir mi presentacion profesional en un formato mas vivo que un CV tradicional, mostrando no solo lo que hago, sino tambien como lo construyo.
